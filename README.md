# Bank Management System - Extension (Level 2) 🏦💳

## 📝 Overview
This is the second major project in the **Algorithms & Problem-Solving Level 3** course. It extends the core Bank System by integrating a professional **Transactions Module**, enabling users to execute real financial operations and manage account balances dynamically.

## 🚀 Key Features
- **Transactions Menu:** Integrated menu to perform Deposits and Withdrawals.
- **Real-time Balance Updates:** Automatically synchronizes financial changes with the `Clients.txt` database.
- **Total Balances Summary:** A dedicated screen to view the sum of all client balances in the system.
- **Advanced Logic & Validation:** Robust handling of "Insufficient Balance" cases and preventing invalid numerical inputs.

## 🛠️ Technical Concepts Used
- **Advanced File Handling:** Advanced techniques for reading, modifying, and rewriting specific data records within text files.
- **Menu-Driven Architecture:** Implementing nested menus for a scalable and better user experience (UX).
- **Financial Logic:** Safe implementation of transaction logic (Addition/Subtraction) ensuring data integrity.

- **تقرير إجمالي الأرصدة:** شاشة مخصصة لعرض مجموع كافة أرصدة العملاء الموجودة في النظام.
- **منطق برمجى متقدم:** معالجة دقيقة لحالات "الرصيد غير الكافي" ومنع المدخلات الرقمية غير الصحيحة.
